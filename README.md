# ISO2HD
Writes .ISO disc images to hard drives in a way that allows them to be bootable on vintage BIOS systems (Non-EFI). 

## Introduction
### History
I recently got the bug to build a vintage gaming PC with the first CPU that I purchased on my own, the infamous Prescott Intel Pentium 4 640. A couple of years later I ended up building this computer into a Hackintosh, so I figured I would attempt to re-live this laborious process. 
### Frustrations
These early hackintosh builds largly relied on custom disk images and required a lot of trial and error to get them working. So I burnt some DVDs (yes I still had some physical media somewhere...) but installing from a disc drive was PAINFULLY slow. Then of course you wait almost an hour for the installation to finish and then nothing boots, or instantly kernel panics, and you're back to square one. So I tried to push these .ISO images to USB drives to no avail. So I needed a new faster solution...

> [!WARNING]
> If you are perturbed by the use of Ai tools for coding tasks, turn away now. This tool was generated by using Claude Code.

### Solution
So I present to you ISO2HD, a Windows PowerShell based tool with a simple GUI to image an .ISO file to a hard drive in a manner that allows the drive to be bootable by BIOS (non-UEFI) firmware PCs. This tool significantly sped up the process of getting my Pentium 4 hackintosh up and running. Installs which took around 45 minutes with the optical disc, now only took 4-5 minutes. Listen, I'm not a developer, and no developer worth their salt would want to spend their time on this niche application. So yes, I used Claude Code to develop this application. 

All that being said, if you've come across this tool while searching for something that can get you installing operating systems on your non-uefi retro PCs from hard drive, then feel free to give this a try!

> I have successfully installed iAtkos v7 and OSXx86 10.4.11 on my Socket 775 Asrock motherboard using drives made with ISO2HD.
